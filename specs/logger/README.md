# logger — Logger Module

Спецификации для модуля логирования Spring Boot Starter.

## Функциональность

- Консольный аппендер логирования с ANSI-цветами
- Файловый аппендер с ротацией по дате, настраиваемым форматированием и буферизацией
- Централизованный LogService для отправки лог-сообщений
- Расширяемая система фильтрации событий через LogFilter
- Сериализация дополнительных объектов в JSON

## Спецификации

- [ConsoleAppender](console-appender-spec.md) — Аппендер для вывода логов в консоль (System.out / System.err) с поддержкой ANSI-цветирования, фильтрации по уровню и сериализации объектов в JSON.
- [FileAppender](file-appender-spec.md) — Аппендер для записи логов в файлы с поддержкой ежедневной ротации, настраиваемого форматирования, буферизации и сериализации объектов.
- [LogService](log-service-spec.md) — Центральный сервис логирования: создание событий, применение фильтров, маршрутизация во все подключённые аппендеры.
- [LogFilter](log-filter-spec.md) — Интерфейс для пользовательской фильтрации событий логирования перед отправкой в аппендеры.
