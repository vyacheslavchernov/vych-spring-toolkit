# specs/ — Спецификации

Каталог содержит спецификации поведения системы. Спецификации описывают **что** система должна делать, а не **как** это реализовано.

## Структура

```
specs/
├── README.md
└── {domain}/
    ├── {feature}.md
    └── ...
```

Подкаталоги отражают предметную область, а не структуру Java-пакетов.

## Разделы

### [logger](logger/)

Спецификации для модуля логирования (logger-spring-boot-starter).

### [http](http/)

Спецификации для модуля HTTP-клиента (http-client-spring-boot-starter).
