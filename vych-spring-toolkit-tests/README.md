# Vych Spring Toolkit — Tests

Интеграционные тесты для проверки работоспособности Spring Boot Starter'ов тулкита в условиях, максимально приближенных к реальному Spring Boot-приложению.

## Назначение

Модуль содержит набор интеграционных тестов, которые проверяют:

* корректную автоконфигурацию стартеров через Spring Boot AutoConfiguration;
* работоспособность HTTP-клиента в условиях, приближенных к продакшену;
* взаимодействие компонентов тулкита между собой;
* корректную работу interceptors для запросов и ответов.

## Запуск тестов

```bash
mvn test
```

## Allure

Генерация отчётов:

```bash
mvn allure:serve
```

## Использование

Этот модуль предназначен **только для внутренних тестов тулкита** и не предназначен для подключения в пользовательских проектах. Он демонстрирует:

* как правильно настраивать `HttpClientBuilder` и `HttpClient` в Spring-приложении;
* как регистрировать и использовать interceptors;
* как тестировать HTTP-клиент с встроенным тестовым сервером;
* как использовать AssertJ и Allure для интеграционных тестов.
